# Maintainers and public ownership

The AssetFare project is maintained by a distributed team under a single
public release namespace during the pilot.

| Responsibility | Public owner or channel |
| --- | --- |
| GitHub and release administration | [`@odaiin`](https://github.com/odaiin) |
| Security reports | `security@assetfare.dev` |
| Code and integration proposals | GitHub pull requests |
| Bugs and ecosystem requests | GitHub issues |

Commits and releases are attributed to the public namespace that performs the
operation. This table intentionally does not invent separate public identities
for contributors who work through that namespace. See
[GOVERNANCE.md](GOVERNANCE.md) for roles and release controls.
